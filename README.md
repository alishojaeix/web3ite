# Web3ite - 3D Website Platform

Premium 3D website builder built with Next.js.

## Features
- Interactive 3D experiences
- Premium templates
- Responsive design
- Motion animations
- Modern UI system

## Tech Stack
- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- Three.js
