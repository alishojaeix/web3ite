# Aldane & Voss (exported from Claude Artifact)

`index.html` is the byte-for-byte published Artifact. It is a single static HTML file
(HTML + inline CSS + inline vanilla JavaScript). No framework, no bundler, no TypeScript, no images.

Run: open `index.html` in a browser, or `npm start` (serves on http://localhost:3000).

External dependencies, loaded at runtime from CDNs (internet required):
- three.js r128   https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
- Lenis 1.1.13    https://cdn.jsdelivr.net/npm/lenis@1.1.13/dist/lenis.min.js
- Google Fonts: Newsreader, Instrument Sans

Only package.json and this README were added; index.html is unmodified.
